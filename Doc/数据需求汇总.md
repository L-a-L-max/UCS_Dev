## 1. 数据链路总览

```
┌─────────────┐    DDS/ROS2     ┌──────────────┐   Kafka/HTTP   ┌──────────────┐  WebSocket/STOMP  ┌──────────────┐
│  PX4飞控     │ ──────────────→ │  DDS网关      │ ─────────────→ │  后端服务     │ ────────────────→ │  前端界面     │
│ (真实/仿真)  │  fmu/out/*     │ (Python)      │ telemetry.raw │ (Java/Spring) │  /topic/*        │ (React/TS)   │
└─────────────┘                 └──────────────┘                └──────────────┘                   └──────────────┘
       ↑                              │                               │                                   │
       │          DDS/ROS2            │         Kafka                 │          WebSocket                 │
       └──────────────────────────────┘    commands.down              │     /topic/command-ack             │
              fmu/in/*                      commands.ack              │     /topic/drone-status            │
              (控制命令下发)                  events.drone              │     /topic/member-status           │
                                                                      │                                   │
                                                                      ├──→ PostgreSQL (持久化)            │
                                                                      └──→ Redis (在线状态/epoch/分区缓存)  │
```

**数据流频率：**
- 遥测数据上行：10Hz/架（DDS网关每0.1s发送一次遥测数据）
- 心跳维持：4Hz/架（OFFBOARD模式下每0.25s发送OffboardControlMode + TrajectorySetpoint）
- 前端刷新：10Hz（WebSocket消息缓冲100ms后批量推送）
- 控制命令下行：按需（用户操作触发）

## 2. DDS网关订阅的PX4话题

DDS网关通过ROS2/DDS订阅以下PX4飞控输出话题（`fmu/out`方向）：

| 序号 | 话题基础名称 | 完整话题路径 | 话题变体（兼容旧版） | 消息类型 | 用途说明 |
|:---:|:---|:---|:---|:---|:---|
| 1 | `vehicle_global_position` | `/{uav_id}/fmu/out/vehicle_global_position` | 无 | VehicleGlobalPosition | GPS全球定位（经纬度、海拔） |
| 2 | `vehicle_local_position` | `/{uav_id}/fmu/out/vehicle_local_position` | `vehicle_local_position_v1` | VehicleLocalPosition | NED本地坐标、速度、Home参考高度 |
| 3 | `vehicle_attitude` | `/{uav_id}/fmu/out/vehicle_attitude` | 无 | VehicleAttitude | 姿态四元数（提取航向角） |
| 4 | `vehicle_status` | `/{uav_id}/fmu/out/vehicle_status` | `vehicle_status_v1` | VehicleStatus | 解锁状态、飞行模式 |
| 5 | `battery_status` | `/{uav_id}/fmu/out/battery_status` | `battery_status_v1` | BatteryStatus | 电池电量百分比 |
| 6 | `vehicle_command_ack` | `/{uav_id}/fmu/out/vehicle_command_ack` | 无 | VehicleCommandAck | 命令执行确认（成功/拒绝） |

> **代码位置：** `dds-gateway/dds_gateway.py` 第61-68行 `TOPIC_SUFFIX_VARIANTS`

DDS网关同时向以下PX4飞控输入话题发布控制消息（`fmu/in`方向）：

| 序号 | 话题路径 | 消息类型 | 用途说明 |
|:---:|:---|:---|:---|
| 1 | `/{uav_id}/fmu/in/vehicle_command` | VehicleCommand | 下发控制命令（起飞/降落/切模式等） |
| 2 | `/{uav_id}/fmu/in/offboard_control_mode` | OffboardControlMode | OFFBOARD模式心跳（位置控制模式声明） |
| 3 | `/{uav_id}/fmu/in/trajectory_setpoint` | TrajectorySetpoint | 位置设定点（NED坐标，用于悬停/前往/盘旋） |

## 3. 各话题字段提取明细

### 3.1 VehicleGlobalPosition（全球定位）

| PX4原始字段 | 提取后变量名 | 数据类型 | 单位 | 说明 |
|:---|:---|:---|:---|:---|
| `msg.lat` | `DroneState.lat` | float64 | 度(°) | WGS84纬度 |
| `msg.lon` | `DroneState.lon` | float64 | 度(°) | WGS84经度 |
| `msg.alt` | `DroneState.alt` | float64 | 米(m) | 海拔高度(AMSL) |

**数据保护逻辑：**
- (0,0)坐标回滚拒绝：当已有有效位置且新坐标接近(0,0)时丢弃
- GPS跳变检测：基于速度模型，若位移超过`(ground_speed + 10) × dt`且大于100m则拒绝
- 高度异常检测：若高度跳变超过500m则拒绝

> **代码位置：** `dds_gateway.py` 第457-513行 `_on_global_position()`

### 3.2 VehicleLocalPosition（本地位置）

| PX4原始字段 | 提取后变量名 | 数据类型 | 单位 | 说明 |
|:---|:---|:---|:---|:---|
| `msg.x` | `DroneState.ned_x` | float64 | 米(m) | NED北向位移（相对Home） |
| `msg.y` | `DroneState.ned_y` | float64 | 米(m) | NED东向位移（相对Home） |
| `msg.z` | `DroneState.ned_z` | float64 | 米(m) | NED下向位移（负值=向上） |
| `msg.vx` | `DroneState.vx` | float64 | m/s | NED北向速度 |
| `msg.vy` | `DroneState.vy` | float64 | m/s | NED东向速度 |
| `msg.vz` | `DroneState.vz` | float64 | m/s | NED下向速度（正值=下降） |
| `msg.ref_alt` | `DroneState.ref_alt` | float64 | 米(m) | Home点海拔高度(AMSL) |

**派生计算：**
- `ground_speed = sqrt(vx² + vy²)` — 地速
- `vertical_speed = -vz` — 垂直速度（正值=上升）
- `ref_alt_valid` — 标记ref_alt是否已获取（仅在ref_alt > 0时为True）

> **代码位置：** `dds_gateway.py` 第515-542行 `_on_local_position()`

### 3.3 VehicleAttitude（姿态）

| PX4原始字段 | 提取后变量名 | 数据类型 | 单位 | 说明 |
|:---|:---|:---|:---|:---|
| `msg.q[0..3]` | （中间变量） | float32[4] | 无量纲 | 姿态四元数 [w, x, y, z] |

**派生计算：**
- `heading = atan2(2*(q[0]*q[3] + q[1]*q[2]), 1 - 2*(q[2]² + q[3]²))` — 航向角（度），范围 [0, 360)

> **代码位置：** `dds_gateway.py` 第544-558行 `_on_attitude()`

### 3.4 VehicleStatus（飞行器状态）

| PX4原始字段 | 提取后变量名 | 数据类型 | 单位 | 说明 |
|:---|:---|:---|:---|:---|
| `msg.arming_state` | `DroneState.armed` | bool | — | 解锁状态（arming_state == 2 表示已解锁） |
| `msg.nav_state` | `DroneState.flight_mode` | string | — | 飞行模式（通过映射表转换） |

**nav_state飞行模式映射表：**

| nav_state值 | 模式名称 | 说明 |
|:---:|:---|:---|
| 0 | MANUAL | 手动模式 |
| 1 | ALTCTL | 高度控制模式 |
| 2 | POSCTL | 位置控制模式 |
| 3 | AUTO_MISSION | 自动任务模式 |
| 4 | AUTO_LOITER | 自动悬停/盘旋 |
| 5 | AUTO_RTL | 自动返航 |
| 14 | OFFBOARD | 外部控制模式 |
| 17 | AUTO_TAKEOFF | 自动起飞 |
| 18 | AUTO_LAND | 自动降落 |
| 其他 | MODE_{N} | 未映射的模式 |

> **代码位置：** `dds_gateway.py` 第560-572行 `_on_vehicle_status()`, 第673-681行 `_nav_state_to_mode()`

### 3.5 BatteryStatus（电池状态）

| PX4原始字段 | 提取后变量名 | 数据类型 | 单位 | 说明 |
|:---|:---|:---|:---|:---|
| `msg.remaining` | `DroneState.battery_percent` | float64 | % | 电池剩余百分比（原始值0-1，乘100转为百分比） |

> **代码位置：** `dds_gateway.py` 第574-585行 `_on_battery_status()`

### 3.6 VehicleCommandAck（命令确认）

| PX4原始字段 | 提取后变量名 | 数据类型 | 说明 |
|:---|:---|:---|:---|
| `msg.command` | `command` | int | MAVLink命令ID（如400=ARM, 176=DO_SET_MODE） |
| `msg.result` | `result` | int | 执行结果码 |

**PX4结果码：**

| result值 | 含义 |
|:---:|:---|
| 0 | ACCEPTED（已接受） |
| 1 | TEMPORARILY_REJECTED（暂时拒绝） |
| 2 | DENIED（拒绝） |
| 3 | UNSUPPORTED（不支持） |
| 4 | FAILED（失败） |
| 5 | IN_PROGRESS（执行中） |
| 6 | CANCELLED（已取消） |

> **代码位置：** `dds_gateway.py` 第587-637行 `_on_vehicle_command_ack()`

| `heading` | float | 0.0 | vehicle_attitude | 航向角（度, 0-360） |
| `ground_speed` | float | 0.0 | vehicle_local_position | 地速（m/s，由vx/vy计算） |
| `vertical_speed` | float | 0.0 | vehicle_local_position | 垂直速度（m/s，正=上升） |
| `vx` | float | 0.0 | vehicle_local_position | NED北向速度（m/s） |
| `vy` | float | 0.0 | vehicle_local_position | NED东向速度（m/s） |
| `vz` | float | 0.0 | vehicle_local_position | NED下向速度（m/s，正=下降） |
| `ned_x` | float | 0.0 | vehicle_local_position | NED北向位移（米，相对Home） |
| `ned_y` | float | 0.0 | vehicle_local_position | NED东向位移（米，相对Home） |
| `ned_z` | float | 0.0 | vehicle_local_position | NED下向位移（米，负=上方） |
| `armed` | bool | False | vehicle_status | 是否解锁 |

| `battery_percent` | float | -1.0 | battery_status | 电池百分比（%） |

## 7. 后端数据处理与持久化

### 7.1 TelemetryKafkaConsumer（遥测消费者）

**消费话题：** `telemetry.raw`

**处理流程：**
1. **Epoch校验** — 丢弃 `epoch < 当前epoch` 的过期消息（防止网关重启后消费旧数据）
2. **时间戳校验** — 丢弃超过30秒的过期消息
3. **标记在线** — `RedisService.setDroneOnline(uavId)`，更新Redis中的在线状态
4. **持久化** — `TelemetryPersistenceService.persistFromMap(payload)` 写入PostgreSQL
5. **分区路由** — `PartitionRoutingService.getPartitionsForDrone(uavId)` 查询该无人机所属的分区
6. **WebSocket推送** — 分区推送 + 全局推送

> **代码位置：** `backend/src/main/java/com/ucs/kafka/TelemetryKafkaConsumer.java` 第48-104行

## 8. WebSocket推送至前端的数据

### 9.4 3D地图特殊数据处理

3D高德地图（`AMap3DPanel`）对数据有额外处理：

- **高度渲染：** `altitude` 通过 `altitudeScaleRef` 比例因子转换为Three.js场景Z轴坐标
- **模型朝向：** `heading` 用于旋转3D无人机模型（球体+旋翼环）
- **信息面板跟随：** 弹窗面板根据 `lngLatToContainer` 将经纬高实时转换为屏幕像素坐标
- **视角聚焦：** 使用无人机经纬度计算 `setZoomAndCenter` + `setPitch(55)` 动画参数
- **追随模式：** 持续将地图中心设为目标无人机的 `[lng, lat]`

## 13. 接入真实无人机的关键差异点

### 13.1 数据源差异

| 差异项 | PX4仿真 | 真实无人机（可能） | 影响 |
|:---|:---|:---|:---|
| DDS话题路径 | `/{uav_id}/fmu/out/*` | 可能不同 | 需要配置话题映射 |
| 话题后缀变体 | `_v1`等版本 | 取决于固件版本 | `TOPIC_SUFFIX_VARIANTS`需要扩展 |
| 消息类型版本 | px4_msgs当前版本 | 可能不同字段 | 需要版本适配层 |
| GPS精度 | 仿真无噪声 | RTK/标准GPS有噪声 | GPS跳变检测阈值需调整 |
| 电池数据 | `remaining`字段 | 可能有voltage/current | 可能需要额外字段 |
| 更新频率 | 稳定10Hz+ | 可能受通信质量影响 | 需要调整超时阈值 |

### 13.2 需要关注的额外数据（当前系统未订阅）

以下PX4话题在真实无人机场景中可能需要新增订阅：

| 话题 | 消息类型 | 用途 | 优先级 |
|:---|:---|:---|:---:|
| `sensor_gps` | SensorGps | GPS原始数据（卫星数、HDOP、定位类型） | 高 |
| `estimator_status` | EstimatorStatus | EKF状态（数据融合质量） | 高 |
| `vehicle_air_data` | VehicleAirData | 气压高度、空速 | 中 |
| `failsafe_flags` | FailsafeFlags | 故障保护标志 | 高 |
| `health_report` | HealthReport | 健康状态报告 | 高 |
| `vehicle_land_detected` | VehicleLandDetected | 着陆检测 | 中 |
| `mission_result` | MissionResult | 任务执行结果 | 低 |
| `vehicle_odometry` | VehicleOdometry | 视觉/惯性里程计 | 低 |
| `wind_estimate` | WindEstimate | 风速估计 | 低 |
| `rc_channels` | RcChannels | 遥控器通道数据 | 中 |

### 13.3 接入建议

1. **话题适配层**：在DDS网关中增加话题映射配置文件，支持不同无人机型号的话题路径差异
2. **消息版本兼容**：对每个话题实现版本检测和字段映射，兼容不同px4_msgs版本
3. **数据质量监控**：增加GPS卫星数、信号强度等数据质量字段，用于前端显示和告警
4. **通信健康度**：增加消息延迟统计和丢包检测，用于判断数据链路质量
5. **渐进式扩展**：优先确保上表中"高优先级"的话题订阅，再逐步添加其他话题
