# UCS 无人机集群管控平台 — 分阶段重构计划

> **版本**：v1.0  
> **日期**：2026-03-20  
> **基于**：《架构升级方案》(v1.0) + 《架构升级01》(v2.0)

> **目标**：从当前单体架构渐进式重构至支撑千万级无人机的分布式架构

## 一、当前架构核心问题总览

在开始重构之前，先明确当前架构存在的 **8 大核心问题**，后续每个阶段的重构任务均围绕解决这些问题展开。

| 编号 | 问题 | 当前表现 | 影响范围 | 严重程度 |
|------|------|---------|---------|---------|
| P1 | **DDS 组播限制** | `dds_gateway.py` 依赖 UDP 组播，无法跨路由器/NAT/公网 | 整体部署架构 | **架构性阻碍** |
| P2 | **单点故障链** | Gateway/Backend/Redis/PostgreSQL 均为单实例 | 系统可用性 | 高 |
| P3 | **消息乱序** | HTTP POST 无序号，多实例部署时同一无人机消息乱序 | 数据一致性 | 高 |
| P4 | **过期消息/断电重连** | 无 epoch 代际机制，断电重连后消费旧数据（armed=true 等） | 飞行安全 | 高 |
| P5 | **事件与流数据混合** | armed 状态变化和位置遥测走同一通道，事件被高频遥测延迟 | 事件实时性 | 中 |
| P6 | **持久化瓶颈** | `ConcurrentLinkedQueue` 无界队列 OOM 风险，JPA saveAll 慢 | 数据持久化 | 高 |
| P7 | **WebSocket 不可扩展** | SimpleBroker 单实例，最大约 5000 连接 | 前端推送 | 高 |
| P8 | **热路径 DB 写入** | 新无人机首次上报触发 `PartitionRoutingService` DB 写入 | 接入延迟 | 中 |

## Phase 1：引入 Kafka + 消息治理（2-3周）

### 1.1 本阶段解决的问题

| 解决问题 | 解决方式 | 效果 |
|---------|---------|------|
| **P3 消息乱序** | Kafka 按 `uav_id` 分区，同一无人机消息严格有序 | 消除多实例部署时的消息乱序 |
| **P4 过期消息/断电重连** | 引入 epoch 代际机制 + 消息时间戳校验 | 断电重连不再消费旧状态数据 |
| **P5 事件与流数据混合** | 事件走独立 Kafka topic `events.drone`，与遥测流分离 | armed 变化等事件不再被遥测延迟 |

### 1.2 核心原则

- **最小改动**：不改变现有部署模式（仍为单机），只在现有代码上叠加 Kafka
- **双写过渡**：Kafka 和 HTTP 并行运行，Kafka 验证稳定后再关闭 HTTP 通道
- **零停机**：整个过程可以分步上线，不需要一次性切换

#### 任务 1.2：Gateway 端添加 Kafka Producer

**改动文件**：`dds-gateway/dds_gateway.py`

**改动内容**：在 `send_to_backend()` 方法中添加 Kafka 写入逻辑，保留 HTTP 作为 fallback。

```python
# dds_gateway.py - 新增Kafka Producer (在__init__中初始化)
from confluent_kafka import Producer

class DDSGateway:
    def __init__(self, ...):
        # ... 现有初始化代码 ...
        
        # 新增: Kafka Producer
        self._kafka_producer = Producer({
            'bootstrap.servers': os.getenv('KAFKA_BROKERS', 'localhost:9092'),
            'linger.ms': 5,
            'batch.size': 65536,
            'compression.type': 'lz4',
            'acks': '1',
        })
        self._use_kafka = os.getenv('ENABLE_KAFKA', 'false').lower() == 'true'
    
    def send_to_backend(self, payload: dict) -> bool:
        """改造: 优先写Kafka, HTTP作为fallback"""
        if self._use_kafka:
            try:
                for drone_data in payload.get('drones', []):
                    uav_id = drone_data.get('uavId', 'unknown')
                    # 按uav_id分区 → 同一无人机消息严格有序
                    self._kafka_producer.produce(
                        topic='telemetry.raw',
                        key=uav_id.encode('utf-8'),
                        value=json.dumps(drone_data).encode('utf-8'),
                    )
                self._kafka_producer.flush(timeout=1.0)
                return True
            except Exception as e:
                self._logger.error(f"Kafka send failed, fallback to HTTP: {e}")
        
        # 原有HTTP逻辑保留作为fallback
        return self._send_http(payload)
```

**新增 `TelemetryKafkaConsumer.java`**：

```java
@Component
@Slf4j
public class TelemetryKafkaConsumer {

    private static final long MAX_AGE_MS = 5000; // 5秒过期阈值
    
    @Autowired private RedisService redisService;
    @Autowired private TelemetryPersistenceService persistenceService;
    @Autowired private WebSocketGatewayService wsService;
    
    // epoch缓存: uavId → 当前epoch
    private final ConcurrentHashMap<String, Long> epochCache = new ConcurrentHashMap<>();

    @KafkaListener(topics = "telemetry.raw", groupId = "ucs-backend")
    public void onTelemetry(ConsumerRecord<String, String> record) {
        String uavId = record.key();
        TelemetryMessage msg = parseMessage(record.value());

        // === 新增: 过期消息检测 (解决P4) ===
        long msgAge = System.currentTimeMillis() - msg.getTimestamp();
        if (msgAge > MAX_AGE_MS) {
            log.debug("Dropping stale message for {}: age={}ms", uavId, msgAge);
            return;
        }

        // === 新增: epoch代际检查 (解决P4) ===
        long currentEpoch = epochCache.getOrDefault(uavId, 0L);
        if (msg.getEpoch() < currentEpoch) {
            log.warn("Dropping stale epoch for {}: msg={} current={}", 
                     uavId, msg.getEpoch(), currentEpoch);
            return;
        }
        if (msg.getEpoch() > currentEpoch) {
            epochCache.put(uavId, msg.getEpoch());
        }

        // 复用现有逻辑
        redisService.setDroneOnline(uavId);
        persistenceService.addTelemetry(msg);
        wsService.broadcastToPartitions(uavId, msg);
    }

    @KafkaListener(topics = "events.drone", groupId = "ucs-backend")
    public void onDroneEvent(ConsumerRecord<String, String> record) {
        DroneEvent event = parseEvent(record.value());
        
        // 断电重连: 重置epoch和状态
        if ("CONNECTED".equals(event.getEventType())) {
            epochCache.put(event.getUavId(), event.getEpoch());
            redisService.resetDroneState(event.getUavId());
            log.info("Drone {} reconnected with epoch={}", 
                     event.getUavId(), event.getEpoch());
        }
        
        // 事件即时推送WebSocket (不受遥测流影响)
        wsService.broadcastEvent(event);
    }
}
```

**验收标准**：

#### 任务 1.4：Gateway 端添加 epoch 代际机制

**改动文件**：`dds-gateway/dds_gateway.py`

```python
class DDSGateway:
    def __init__(self, ...):
        # 新增: 每架无人机的epoch (断电重连时递增)
        self._drone_epochs: Dict[str, int] = {}
    
    def _on_drone_connected(self, uav_id: str):
        """新增: 无人机连接时分配/递增epoch"""
        prev_epoch = self._drone_epochs.get(uav_id, 0)
        new_epoch = prev_epoch + 1
        self._drone_epochs[uav_id] = new_epoch
        
        # 发送连接事件
        self._kafka_producer.produce(
            topic='events.drone',
            key=uav_id.encode('utf-8'),
            value=json.dumps({
                'uavId': uav_id,
                'eventType': 'CONNECTED',
                'epoch': new_epoch,
                'timestamp': int(time.time() * 1000),
            }).encode('utf-8'),
        )
    
    def _build_telemetry_payload(self, uav_id: str, data: dict) -> dict:
        """改造: 每条遥测消息携带epoch"""
        data['epoch'] = self._drone_epochs.get(uav_id, 0)
        data['timestamp'] = int(time.time() * 1000)
        return data
```

@Autowired private KafkaTemplate<String, String> kafkaTemplate;

public String sendCommand(String uavId, String commandType, String params) {
    String commandId = UUID.randomUUID().toString();
    CommandMessage cmd = CommandMessage.builder()
        .commandId(commandId)
        .uavId(uavId)

```python
# dds_gateway.py - 新增Kafka Consumer线程消费命令
from confluent_kafka import Consumer

def _start_command_consumer(self):
    consumer = Consumer({
        'bootstrap.servers': os.getenv('KAFKA_BROKERS', 'localhost:9092'),
        'group.id': 'gateway-command',
        'auto.offset.reset': 'latest',
    })
    consumer.subscribe(['commands.down'])
    
    while self._running:
        msg = consumer.poll(timeout=0.1)
        if msg is None or msg.error():
            continue
        cmd = json.loads(msg.value().decode('utf-8'))
        
        # 检查命令是否过期
        if int(time.time() * 1000) > cmd.get('expireAt', 0):
            self._logger.warn(f"Command expired: {cmd['commandId']}")
            continue
        
        # 执行命令 (复用现有DDS发送逻辑)
        self._execute_command(cmd['uavId'], cmd['commandType'], cmd['params'])
        
        # 发送ACK
        self._kafka_producer.produce(
            topic='commands.ack',
            key=cmd['uavId'].encode('utf-8'),
            value=json.dumps({
                'commandId': cmd['commandId'],
                'uavId': cmd['uavId'],
                'success': True,
                'timestamp': int(time.time() * 1000),
            }).encode('utf-8'),
        )
```

## Phase 2：微服务拆分 + 数据层升级（3-4周）

### 2.1 本阶段解决的问题

#### 任务 2.2：拆分 ucs-telemetry-ingest（遥测接入服务）

**来源**：从现有 `DDSGatewayController.receiveTelemetry()` 中提取

**职责边界**：
- 消费 Kafka `telemetry.raw` topic
- 过期消息检测 + epoch 代际校验（Phase 1 已实现的逻辑）
- 更新 Redis Cluster 中的无人机最新状态
- **不做**持久化（由 ucs-telemetry-store 负责）
- **不做** WebSocket 推送（由 ucs-realtime-push 负责）

**关键代码**：

```java
@Service
public class TelemetryConsumer {

    @Autowired private RedisClusterService redisService;
    @Autowired private EpochValidationService epochService;

    @KafkaListener(topics = "telemetry.raw", groupId = "ingest-group", 
                   concurrency = "16")  // 16个消费线程
    public void onTelemetry(ConsumerRecord<String, String> record) {
        String uavId = record.key();
        TelemetryMessage msg = JsonUtil.parse(record.value(), TelemetryMessage.class);

        // 过期检测 + epoch校验
        if (!epochService.validate(uavId, msg)) {
            return;
        }

        // 更新Redis Cluster状态 (Hash结构)
        Map<String, String> stateMap = Map.of(
            "lat", String.valueOf(msg.getLat()),
            "lon", String.valueOf(msg.getLon()),
            "alt", String.valueOf(msg.getAlt()),
            "heading", String.valueOf(msg.getHeading()),
            "speed", String.valueOf(msg.getGroundSpeed()),
            "armed", String.valueOf(msg.isArmed()),
            "epoch", String.valueOf(msg.getEpoch()),
            "lastUpdate", String.valueOf(System.currentTimeMillis())
        );
        redisService.hsetAll("drone:" + uavId + ":state", stateMap);
        redisService.expire("drone:" + uavId + ":state", 30);
    }
}
```

@Service
public class StoreBatchConsumer {

    @Autowired private JdbcTemplate jdbcTemplate;

    // Kafka批量消费 (替代ConcurrentLinkedQueue, 解决OOM)
    @KafkaListener(topics = "telemetry.raw", groupId = "store-group",
                   concurrency = "8",
                   properties = {
                       "max.poll.records=500",       // 每批最多500条
                       "fetch.min.bytes=65536"        // 至少64KB才拉取
                   })
    public void onBatch(List<ConsumerRecord<String, String>> records) {
        List<Object[]> batchArgs = records.stream()
            .map(r -> JsonUtil.parse(r.value(), TelemetryMessage.class))
            .map(msg -> new Object[]{
                msg.getUavId(), msg.getLat(), msg.getLon(), msg.getAlt(),
                msg.getHeading(), msg.getGroundSpeed(), msg.isArmed(),
                new Timestamp(msg.getTimestamp())
            })
            .collect(Collectors.toList());

        // JDBC批量写入 (比JPA saveAll快100倍)
        jdbcTemplate.batchUpdate(
            "INSERT INTO uav_telemetry (uav_id,lat,lon,alt,heading,ground_speed,armed,timestamp) " +
            "VALUES (?,?,?,?,?,?,?,?)",
            batchArgs
        );
    }
}

```java
@Service
@Slf4j
public class ZenohGatewayService {
    
    @Autowired private KafkaTemplate<String, String> kafkaTemplate;
    private Session zenohSession;
    private final Map<String, Subscriber> subscribers = new ConcurrentHashMap<>();
    private final Map<String, Long> droneEpochs = new ConcurrentHashMap<>();

    @PostConstruct
    public void init() throws ZenohException {
        Config config = Config.loadFromFile("zenoh-config.json5");
        this.zenohSession = Zenoh.open(config);
        log.info("Zenoh session opened");
    }

    public void subscribeDrone(String uavId) {
        String keyExpr = uavId + "/fmu/out/**";
        Subscriber sub = zenohSession.declareSubscriber(keyExpr, sample -> {
            String topic = sample.getKeyExpr().toString();
            byte[] payload = sample.getPayload();
            
            if (topic.contains("vehicle_global_position")) {
                handlePosition(uavId, payload);
            } else if (topic.contains("vehicle_status")) {
                handleStatus(uavId, payload);
            }
        });
        subscribers.put(uavId, sub);
    }

    private void handlePosition(String uavId, byte[] payload) {
        VehicleGlobalPosition pos = CdrDeserializer.deserialize(payload, VehicleGlobalPosition.class);
        TelemetryMessage msg = TelemetryMessage.builder()
            .uavId(uavId)
            .lat(pos.getLat()).lon(pos.getLon()).alt(pos.getAlt())
            .timestamp(System.currentTimeMillis())
            .epoch(droneEpochs.getOrDefault(uavId, 0L))
            .build();
        kafkaTemplate.send("telemetry.raw", uavId, JsonUtil.toJson(msg));
    }

    public void sendCommand(String uavId, VehicleCommand cmd) {
        byte[] payload = CdrSerializer.serialize(cmd);
        zenohSession.put(uavId + "/fmu/in/vehicle_command", payload);
    }
    
    @PreDestroy
    public void cleanup() {
        subscribers.values().forEach(Subscriber::close);
        if (zenohSession != null) zenohSession.close();
    }
}
```

#### 任务 4.5：GeoHash 空间索引

**在 Redis Cluster 中维护无人机 GeoHash 索引**：

```java
// 更新无人机位置时同时更新GeoHash索引
public void updateDronePosition(String uavId, double lat, double lon) {
    // GeoHash精度6位 (~1.2km×0.6km)
    String geoHash = GeoHash.encodeHash(lat, lon, 6);
    
    // Redis GEO命令
    redisCluster.geoadd("drone:positions", lon, lat, uavId);
    
    // 维护GeoHash反向索引 (用于视口查询)
    redisCluster.sadd("geohash:" + geoHash, uavId);
}

// 查询视口内的无人机
public Set<String> getDronesInViewport(double minLat, double maxLat, 
                                        double minLon, double maxLon) {
    // 计算视口覆盖的GeoHash格子
    Set<String> geoHashes = GeoHash.coverBoundingBox(minLat, maxLat, minLon, maxLon, 6);
    
    Set<String> result = new HashSet<>();
    for (String hash : geoHashes) {
        result.addAll(redisCluster.smembers("geohash:" + hash));
    }
    return result;
}
```

**验收标准**：
- [ ] 视口查询 <10ms 返回结果
- [ ] 千万级无人机场景下 GeoHash 索引内存 <2GB

## 五、风险提示与注意事项

| 风险 | 影响 | 缓解措施 |
